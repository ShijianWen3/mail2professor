# mail2professor · AI 联系导师助手

<div align="center">
  <img src="./icons/icon128_new.png" alt="mail2professor 图标" width="96" />
</div>

一个 Chrome / Edge 扩展，帮助你从导师主页收集信息、搜索研究方向、管理联系进度，并起草个性化联系邮件。研究方向评价功能还会联网查找公开资料，按目标画像汇总成蛛网图，供你参考。

> **当前版本：2.3.1**（版本号以 [`manifest.json`](./manifest.json) 为准）

## 功能

- **Agent 式任务流程**：读取当前页面，按需搜索网页、访问相关链接、保存导师信息并生成邮件草稿；任务执行过程会显示在侧边栏。
- **导师库与跟进**：按 `new → drafted → contacted → replied → meeting → offer / declined` 管理联系进度，可导出 JSON。
- **研究方向评价**：根据公开信息评价 7 个维度，并检查资源可获得性；支持读博、硕士就业、出国申请三种目标画像和蛛网图展示。
- **个人资料与邮件草稿**：保存个人背景，供邮件生成使用；草稿可在确认后打开本地邮件客户端发送。
- **多模型配置**：分别保存各模型厂商的 API Key、BASE URL 和模型设置，切换厂商时互不覆盖。

## 安装

1. 在 Chrome 打开 `chrome://extensions/`，或在 Edge 打开 `edge://extensions/`。
2. 开启右上角的**开发者模式**。
3. 点击**加载已解压的扩展程序**，选择本项目文件夹。
4. 点击扩展图标打开侧边栏。

## 使用

1. 点击扩展图标打开侧边栏。首次使用时，按提示进入**模型设置**，配置模型厂商、API Key 和模型信息。
2. 在**我的资料**填写姓名、院校、专业、成绩排名、奖项、技能、科研经历和联系方式。输入会自动保存。
3. 打开导师主页，进入**生成联系邮件**并选择或编辑任务描述，然后开始任务。可从实时执行记录查看 Agent 的思考、工具调用和结果。
4. 在邮件确认页检查、修改草稿，再选择打开邮件客户端。
5. 在**导师库**查看导师及跟进状态；需要评估研究方向时，点击对应的评价入口。

任务页提供三种常用预设：

| 预设 | 工作内容 |
| --- | --- |
| 分析并写邮件 | 读取当前页面、保存导师并起草邮件 |
| 深挖研究方向 | 搜索论文和课题组信息，梳理联系切入点并完善邮件 |
| 整理本页导师 | 从师资列表页逐位整理导师姓名和主页链接 |

## 研究方向评价

评价针对**研究方向的投入价值**，不是对导师个人进行评价。七个维度包括基础匹配度、成长势能、产业需求度、就业弹性、学术天花板、毕业可达性和竞争友好度；另设资源可获得性闸门。结果以四档和依据链接呈现，不以小数分制造精确感。

评价结果可按读博、硕士就业或出国申请目标重新加权；切换目标画像只会在本地重新计算，不会再次调用模型。评价依赖公开搜索结果，数据覆盖程度和结论质量会受到搜索来源影响。

## 隐私与限制

- API Key、个人资料和导师库保存在浏览器本地的 `chrome.storage.local`，不会上传到本项目的服务器。
- 为执行任务，当前页面内容和相关提示会发送给你配置的模型厂商；请勿在不适合的敏感网络环境中使用。
- 需要登录的页面可能只能读取到未登录内容。Chrome PDF 阅读器中的页面无法由扩展直接读取，可按 Agent 提示手动处理。
- 网页搜索依赖公开搜索入口；搜索服务或页面结构变化可能影响结果。
- 关闭侧边栏会中断正在运行的任务。

## 开发自检

需要安装 Node.js。运行单元测试：

```bash
node --test tests/smoke.test.mjs
```

运行端到端验证：

```bash
node tools/e2e-verify.mjs
```

端到端脚本会启动本地模拟模型和测试页面，使用 Chrome 验证扩展的实际 UI 流程，不调用外部模型 API，也不需要真实 API Key。Chrome 137 及以上版本通过 CDP 的 `Extensions.loadUnpacked` 加载未打包扩展。

## 版本记录

- **2.3.1（当前）**：修复研究方向评价参数因输出长度截断而导致整轮任务失败的问题。评价参数解析失败后会将错误反馈给模型重试；放宽评价输出预算，并改进错误信息以区分截断与格式错误。
- **2.3**：新增研究方向评价，支持联网搜索、七维分档、蛛网图，以及读博 / 就业 / 出国三种目标画像。
- **2.2**：各模型厂商的 API Key、BASE URL 和模型配置分开保存；改进任务输入框和预设提示词的展示。
- **2.1**：改为多页面侧边栏，扩充个人资料字段并支持自动保存，加入持久化写入校验。
- **2.0**：加入可调用工具的 Agent 循环，支持读取页面、搜索网页、管理导师和起草邮件。
- **1.0**：将页面内容交给模型一次性分析并生成邮件。

## 项目结构

```text
manifest.json          Chrome 扩展配置
background.js          点击扩展图标时打开侧边栏
content.js             页面正文、邮箱和链接提取
sidepanel.html/js      侧边栏界面与任务编排
lib/                   模型适配、Agent、工具、评价、蛛网图和数据存储
tests/smoke.test.mjs   单元测试
tools/e2e-verify.mjs   端到端验证
dev.md                 开发设计与实现说明
```
